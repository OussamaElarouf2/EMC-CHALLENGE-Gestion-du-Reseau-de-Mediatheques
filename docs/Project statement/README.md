# PFE Challenge EMC — Par où commencer

Les candidats qui réussiront le challenge se verront proposer un PFE au sein d'Education Media Company, au Technopark Souss Massa à Agadir, avec une perspective de préembauche à l'issue du stage.

## Ce que contient cette archive

| Élément | Contenu |
|---|---|
| `README.pdf` et `README.md` | Ce guide. |
| `pdf/` | L'énoncé en PDF, prêt à lire ou à imprimer. |
| `md/` | Le même énoncé en Markdown, pratique pour le copier dans vos outils, IA comprise. |

Les deux dossiers disent la même chose : choisissez le format que vous préférez.

## Dans quel ordre lire

1. **`00-demarche`** : le cadre, les livrables et le barème. À lire en premier.
2. **Un sujet à choisir parmi quatre** : `sujet-1-billetterie`, `sujet-2-restaurant`, `sujet-3-covoiturage`, `sujet-4-mediatheque`.

## L'essentiel

- Vous choisissez **un seul sujet**, et le réalisez avec **Symfony 7.4** et **MySQL**.
- Vous avez **7 jours** : date limite **dimanche 15 novembre 2026 à 23h59** (heure du Maroc).
- Votre travail vit dans un **dépôt GitHub public**, sur votre propre compte, avec un historique complet du premier au dernier jour.
- L'IA est autorisée. Partagez vos traces d'usage : elles rapportent des points bonus.

## À envoyer à pfe@educationmedia.ma avant la date limite

1. le lien de votre dépôt GitHub public ;
2. le sujet choisi ;
3. votre note conceptuelle d'une page (PDF) ;
4. l'archive ZIP de vos traces IA (bonus).

Une question ? Écrivez à pfe@educationmedia.ma.
